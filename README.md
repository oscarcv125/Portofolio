# Interactive 3D Portfolio

A highly interactive, modern web portfolio showcasing my projects and technical skills as a developer.

## 🚀 Technical Architecture

### Frontend Framework
- **React & Vite**: Built for speed and optimized production builds.
- **React Router v6**: Client-side routing with clean URLs.

### 3D Graphics & Physics
- **Three.js & React Three Fiber (@react-three/fiber)**: Renders the complex 3D environments and interactive elements directly in the browser.
- **Rapier Physics (@react-three/rapier)**: Handles real-time, lightweight 3D physics simulations.
- **Drei (@react-three/drei)**: Utility ecosystem for advanced 3D helpers and controls.

### Animations & Styling
- **Framer Motion**: Powers the seamless page transitions (`AnimatePresence`) and scroll progress indicators.
- **Anime.js**: Utilized for micro-animations and complex sequence timelines.
- **Tailwind CSS & Styled-Components**: A hybrid styling approach combining utility-first CSS with dynamic, component-scoped styles.

### Analytics & SEO
- **React-GA4**: Google Analytics 4 integration for user tracking.
- **React-Helmet**: Dynamic document head management for optimized SEO across routes.
