# Personal Portfolio

Welcome to my personal portfolio repository! This project showcases my skills and experience as a developer.

## Technologies Used
- **React** & **Vite** for a fast and modern frontend framework.
- **Three.js** (@react-three/fiber, @react-three/drei) for immersive 3D web experiences.
- **Tailwind CSS** and **styled-components** for responsive and modular styling.
- **Framer Motion** and **Anime.js** for smooth, complex animations.

This portfolio is designed to be highly interactive and visually engaging, highlighting my expertise in modern web technologies and 3D graphics.
